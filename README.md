# Portfólio — Lucas Neves

Site estático (HTML, CSS e JS puros). Abra o `index.html` ou publique no GitHub Pages.

- **Fontes** (Syne, Inter e Space Mono) ficam em `fonts/`, sem depender de CDN.
- **Prints dos projetos** ficam em `images/` (veja `images/LEIA-ME.txt`). O script `tools/capture-prints.js` tira todos de uma vez.
- **Imagem de compartilhamento** é `og-image.png`. As meta tags em `index.html` apontam para `https://luksn02.github.io/Portf-lio/og-image.png`; se o site for publicado em outro endereço, ajuste essa URL.
- **Idiomas:** PT/EN no botão do topo; as traduções estão no começo de `script.js`.
